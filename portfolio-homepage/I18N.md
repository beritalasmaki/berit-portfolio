# Languages (English / Finnish)

English is the default and keeps the original URLs. Finnish lives under `/fi`.

| Page | English | Finnish |
|---|---|---|
| Home | `/` | `/fi` |
| Blog | `/blog` | `/fi/blogi` |
| Post | `/blog/<slug>` | `/fi/blogi/<finnish-slug>` |
| Case study | `/usecases/<slug>` | `/fi/tyot/<finnish-slug>` |

Internally there is one route tree, `src/app/[locale]/…`; `next.config.mjs` maps the public URLs onto it and
redirects the internal ones. All links are built in `src/i18n/paths.ts`; never hand-write a path.

## Where the copy lives

- **Everything except case studies and posts:** `src/i18n/dictionaries/en.ts` and `fi.ts`. `fi.ts` is type-checked
  against `en.ts`, so a missing key fails `npm run typecheck`.
- **Case studies:** `src/data/case-studies/*.ts` (English) and `src/data/case-studies/fi/*.ts` (Finnish). Finnish URL
  slugs are in `src/data/case-studies/slugs.ts`. Images and pixel sizes come from the English file.
- **Blog posts:** `src/data/blog/*.ts` and `src/data/blog/fi/*.ts`. A Finnish post sets `translationOf` to the English
  slug, which wires the language switcher and `hreflang`. A post with no translation simply exists in one language.

## Adding a Finnish translation of a new post

1. Copy the English post file into `src/data/blog/fi/`, translate it, give it a Finnish `slug`, set `translationOf`.
2. Register it in `src/data/blog/index.ts` (`registries.fi`). Links to other posts must use `/fi/blogi/<slug>`.

## SEO

- Per-page title, description, canonical, `hreflang` and Open Graph: `src/lib/seo.ts`.
- Structured data (Person, WebSite, ProfilePage, BlogPosting, BreadcrumbList): `src/lib/jsonld.tsx`.
- `sitemap.xml` and `robots.txt`: `src/app/sitemap.ts`, `src/app/robots.ts`.
- Set `NEXT_PUBLIC_SITE_URL=https://www.beritalasmaki.com` in Vercel so canonicals and the sitemap use the real domain.
- Social preview images: `public/og/og-en.png`, `og-fi.png` (1200×630).
